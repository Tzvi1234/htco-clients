# Contributing

HTCO is developed by H.T.Z Studios with AI coding agents. External contributions are not accepted at this time.

The workflow is the same as the platform's ([CONTRIBUTING](https://github.com/Tzvi1234/htco-platform/blob/main/CONTRIBUTING.md)): start from a planned slice, write acceptance criteria and failing tests first, verify for real, update docs in the same pull request, open a pull request with a Conventional Commit title, squash merge after green CI.

Client additions:

- Follow the [design system](design/README.md) and the [component specification](design/COMPONENT_SPEC.md); new patterns need the owner's agreement.
- Attach screenshots of every changed state in Hebrew and English, light and dark, to the pull request (never with real buyer data).
- Complete the accessibility checklist in the pull request template.
