# Architecture Decision Records — clients

Decisions specific to the web, Windows and Android clients and the design system. They are titled **Client ADR-NNNN** so they are never confused with the platform's ADRs of the same number. System-wide decisions live in [`htco-platform/docs/adr`](https://github.com/Tzvi1234/htco-platform/tree/main/docs/adr), which also defines the format, the rules and the template used here.
