# Features

Every client feature has a folder here, created from [`_template/`](_template/) at the start of its first slice. The [`feature-docs`](../../.claude/skills/feature-docs/SKILL.md) skill explains each file. When the feature also has a platform side, its folder links to the matching folder in `htco-platform/docs/features/`.
